# Node

A node is a fundamental building block of a workflow in jAI Workflow. It represents a specific task or operation that can be performed within the workflow. Nodes can be connected to form a sequence of operations, allowing for complex workflows to be created.

## Types of Nodes
There are several types of nodes in jAI Workflow, each serving a different purpose:

- **Generic Node**: A basic node that can perform any operation. It is the most flexible type of node and can be used for a wide range of tasks.
- **Split Node**: A node that splits the workflow into multiple branches. It allows for parallel processing of tasks, enabling more complex workflows to be created.
- **Merge Node**: A node that merges multiple branches of the workflow back into a single branch. It is used to combine the results of parallel processing tasks.
- **Conditional Node**: A node that allows for conditional branching in the workflow. It can be used to create workflows that adapt to different conditions or inputs.
