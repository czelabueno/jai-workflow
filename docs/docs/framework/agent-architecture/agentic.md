# Agentic System
An agentic system is a system that can act autonomously and make decisions based on its environment. It is capable of perceiving its surroundings, processing information, and taking actions to achieve specific goals. Agentic systems are often designed to operate in dynamic and complex environments, where they must adapt to changing conditions and learn from their experiences.

## Reference Architectures
jAI Workflow is designed with a modular architecture, enabling you to define custom workflows, modules, or agents to build RAG systems as LEGO-like. A module can be decoupled and integrated into any other workflow.
