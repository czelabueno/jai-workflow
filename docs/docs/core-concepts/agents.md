# Agent concept

## What is an AI agent?
An AI agent is a software program that can autonomously perform tasks or make decisions based on its environment. In the context of jAI Workflow, agents are designed to leverage the capabilities of multimodal models to carry out complex workflows.

## Why use agents?
Agents are useful for automating repetitive tasks, improving efficiency, and enabling more sophisticated interactions with users. By using agents, you can create applications that can adapt to changing conditions and provide personalized experiences.

## Key components of an agent
1. **Model (e.g: Large Language Model)**: The core component of an agent that processes and generates text.
2. **Tools**: External resources or APIs that the agent can use to perform specific tasks.
3. **Memory**: A mechanism for storing and retrieving information that the agent can use to maintain context and continuity in its interactions. These can be _short-term_ or _long-term_ memories, depending on the use case.
4. **Instructions**: The guidelines or rules that define how the agent should behave and respond to different situations.
5. **Response Type**: The output generated by the agent based on its inputs and instructions based in a **POJO**, `JSON` format or a `String`.
